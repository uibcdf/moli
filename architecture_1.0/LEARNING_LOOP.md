# Learning Loop

The dynamic scientific view is a learning loop:

```text
KNOW → MODEL → DO → DISCOVER → LEARN
 ▲                              │
 └──────────────────────────────┘
```

`LEARN` represents controlled accumulation of scientific context, not merely the end of a workflow.

## Nextia retains experience

Nextia preserves project-specific history: what was asked, tried, observed, supported, contradicted, rejected, failed, superseded, and decided.

## Learning may be promoted

```text
Nextia experience
      ├── consolidated / curated knowledge → Sabueso
      └── validated / generalized methodology → Praxis
```

Promotion is explicit. A project Result does not automatically become resolved Sabueso knowledge, and an ad-hoc successful workflow does not automatically become a validated Praxis Capability.

## Accumulation

`iteration n → DISCOVER → LEARN → richer Knowledge + Know-how + retained Experience → iteration n+1`

Organizational learning therefore does not require continuous retraining of an LLM. Nextia retains discovery experience; selected, explicitly curated knowledge may enter Sabueso, and validated/generalized methodological know-how may enter Praxis.

> **LEARN closes the loop from Discovery back to KNOW.**
