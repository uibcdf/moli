# Migration from previous Architecture 1.0 packages

This package supersedes all earlier Architecture 1.0 design packages.

- Keep Knowledge / Modeling / Capabilities / Discovery as the functional view.
- Group Sabueso/Praxis/Nextia conceptually as Scientific Context, not Molecular Intelligence.
- Keep MolSysSuite as the modeling ecosystem, explicitly interoperable with Scientific Context.
- Keep MOLI Agent optional across both.
- Reserve Molecular Intelligence for Scientific Context + Molecular Modeling + Scientific Reasoning.
- Conceptual bidirectionality does not imply circular package dependencies.
- Sabueso Evidence terminology migrates to SourceAssertion / SourceAssertionStore / source_assertion_ids.
- Nextia retains Evidence; Provenance remains cross-cutting.
