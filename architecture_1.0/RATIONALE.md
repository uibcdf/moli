# Architectural Rationale

Sabueso, Praxis, and Nextia provide persistent scientific context — knowledge, know-how, and discovery experience. `Scientific Context` describes this without implying AI or claiming these systems alone constitute intelligence.

MolSysSuite remains the molecular modeling ecosystem, explicitly connected to Scientific Context.

MOLI Agent is optional because Molecular Intelligence must remain possible with human scientific reasoning alone.

Three complementary views are retained:
- structural: Scientific Context ↔ MolSysSuite;
- functional: Knowledge | Modeling | Capabilities | Discovery;
- dynamic: KNOW → MODEL → DO → DISCOVER → LEARN.

Sabueso SourceAssertion, Nextia Evidence, and cross-cutting Provenance remain deliberately distinct.
