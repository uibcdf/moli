# Future Directions

The architecture should absorb new forms of Scientific Context and new molecular modeling methods without collapsing their distinct semantic ownership.

## MolSysSuite modeling
- free-energy calculations;
- quantum chemistry;
- property prediction / ADMET;
- QSAR;
- generative chemistry;
- retrosynthesis;
- protein/peptide design;
- advanced conformational sampling;
- molecular/material design beyond pharmacology.

## Scientific Context
### Sabueso
Structured literature/patent knowledge, richer relationships, semantic knowledge queries, temporal knowledge, private curated knowledge.

### Praxis
Public/private Capability registries, validation benchmarks, protocol selection using accuracy/cost/resources/uncertainty, organization-specific know-how.

### Nextia
Project templates, richer uncertainty/evidence graphs, experimental ingestion, multi-objective discovery, cross-project learning, possible portfolio/program structures if real use requires them.

## MOLI Agent
Richer scientific planning, uncertainty-aware proposals, capability composition, reviewable Protocol drafting, and deeper organizational learning across Sabueso/Praxis/Nextia.

## Physical loop
Long term, the platform can close computation → experiment → learning loops, including laboratory automation, without making robotics part of Nextia's core ontology.
