# Design Principles

1. Scientific Context provides structured persistent context; it is not synonymous with AI.
2. MolSysSuite provides molecular modeling and may consume Scientific Context directly.
3. Molecular Intelligence emerges from Scientific Context + Molecular Modeling + Scientific Reasoning.
4. MOLI Agent is optional; reproducible science works without it.
5. Ownership does not imply isolation.
6. Conceptual interoperability does not require circular package dependencies; use stable interfaces/adapters.
7. Sabueso, Praxis, and Nextia retain distinct epistemic ownership.
8. SourceAssertion ≠ Evidence ≠ Provenance.
9. Capabilities do not hide expert APIs.
10. Capability promotion requires validation.
11. Discovery is graph-shaped.
12. DiscoveryProject state/history ≠ DiscoveryEngine action.
13. Strategy ≠ Protocol; Campaign ≠ Protocol.
14. Artifact ≠ Result ≠ Observation ≠ Evidence.
15. External knowledge does not automatically become project Evidence.
16. Candidate is optional/type-agnostic.
17. Stable references/provenance are first-class.
18. Failure, contradiction, inconclusive, rejected, and superseded states are meaningful.
19. Human agency/approval gates are first-class.
20. Compose external scientific engines where appropriate.
21. Discovery improves knowledge and methodology.
22. Avoid pharmacology-specific core assumptions.
23. AI-generated methodology is not automatically validated methodology.
