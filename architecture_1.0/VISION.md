# Vision

The MOLI Platform supports **Molecular Intelligence**: the ability to understand, investigate, learn about, and create molecular systems by combining structured scientific context, molecular modeling, and scientific reasoning.

- **Scientific Context:** Sabueso (Knowledge), Praxis (Know-how), Nextia (Discovery).
- **MolSysSuite:** molecular representation, interoperability, simulation, analysis, and visualization, assisted by its specialist agent MolSys-AI.
- **Scientific Reasoning:** human-only or augmented by optional MOLI Agent.

MOLI's context is richer than document retrieval alone. Structured Context Assembly can preserve source assertions, conflicts, methodological validation, project history, failures, Evidence, and Decisions while retaining references to authoritative objects.

> Scientific Context provides context. MolSysSuite models. Scientists and MOLI reason and act. Together they produce Molecular Intelligence.

The platform remains scientifically usable without an LLM.

`KNOW → MODEL → DO → DISCOVER → LEARN → KNOW`
