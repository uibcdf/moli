# Core Concepts

## Sabueso
**SourceAssertion:** traceable assertion made by an external/curated source about an entity/property.  
**Resolved Knowledge:** knowledge resolved from SourceAssertions while preserving conflicts and traceability.

## Praxis
**Capability:** WHAT we know how to do.  
**Protocol:** HOW a Capability is performed reproducibly.

## Nextia
**Focus, Goal, Question, Hypothesis, Strategy, Campaign, Run, Artifact, Result, Observation, Evidence, Candidate, Decision.**

**Evidence:** project-contextual scientific information supporting, contradicting, or informing a Question/Hypothesis.

## Cross-cutting
**Provenance:** origin, lineage, transformations, versions, and production context.

## Normative boundaries
SourceAssertion ≠ Evidence ≠ Provenance  
Sabueso Knowledge ≠ Nextia project experience  
Capability ≠ Protocol  
Strategy ≠ Protocol  
Campaign ≠ Protocol  
DiscoveryProject ≠ DiscoveryEngine  
Artifact ≠ Result ≠ Observation ≠ Evidence  
Entity ≠ Candidate  
Target is contextual, not intrinsic  
Molecular Intelligence ≠ MolSysSuite  
MOLI Agent ≠ Molecular Intelligence
