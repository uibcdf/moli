# MOLI developer-guide instructions

Read the root `../AGENTS.md` and `../MOLI_GUIDE.md` for repository-wide rules.
Use `README.md` to find maintained governance documents and current work.
Active issue-backed analyses live in `pending_bugs/` and `pending_proposals/`;
`archive/` preserves resolved or superseded history. Read an archived report
when tracing a decision or migration, not as the current rule without checking
its replacement.

Before filing or closing an issue-backed report, follow
`governance/reporting_protocol.md`. Keep bug facts and technical decisions in
their issue, tests and maintained documents. Only accepted, lasting agent
working instructions go in the correctly scoped `AGENTS.md` under
`governance/agent_instruction_lifecycle.md`; platform-wide instructions belong
in the root file and its normative policy.
