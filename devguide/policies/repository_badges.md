# MOLI Repository Badge Policy

Badges make bounded claims and must point to authoritative evidence.

## Baseline

A MOLI repository README should identify its MOLI role/governance relationship, applicable Python support when relevant, and license. A live governance/policy workflow badge may be included only when the workflow exists.

## Conditional badges

Tests, coverage, documentation, release, DOI, and distribution badges appear only when the corresponding capability is real and maintained.

A static green badge must not replace live evidence. Absence is better than an unsupported claim.

MolSysSuite may add domain-specific role badges for its internal members while inheriting these evidence principles.
