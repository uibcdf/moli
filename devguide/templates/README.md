# Governance Templates

Shared reporting templates may be added here when repeated MOLI governance work demonstrates the need.

Use [component agent-instruction snippets](component_agent_instructions.md) when
adopting the [agent-instruction lifecycle](../governance/agent_instruction_lifecycle.md).
Adapt the text to the repository; do not replace existing local instructions.

Use the [release/publication notice](release_publication_notice.md) for an actual
release or package event under the [notice policy](../governance/release_publication_notices.md).
External issue/PR drafts need the named human approval before remote publication;
follow the [authority rule](../governance/external_publication_authority.md).
